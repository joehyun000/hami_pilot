## 1. 정리 원칙

다음 기준으로 자료를 분류한다.

1. 현재 HAMi 파일럿의 설계·구현·재현에 직접 필요한가?
2. 현재 연구 질문과 다른 과거 주제를 다시 끌어들이는가?
3. 실제 GPU 결과와 합성 결과를 혼동하게 만드는가?
4. 같은 내용을 서로 다르게 설명하는 중복 문서인가?
5. 앞으로 한 위치에서 최신 내용을 찾을 수 있는가?

현재 연구의 기준 문서는 다음 두 개로 통일한다.

## 5. 현재 HAMi 파일럿 안에서 보존할 결과 구분

다음 원칙을 적용한다.

- 코드 연결 확인용 합성 결과는 실제 연구 결과와 분리한다.
- 실제 GPU를 사용하지 않은 결과에는 항상 “연구 증거가 아님”을 표시한다.
- 실제 GPU 결과는 환경 확인, 요청량 선택, 조건 확인용 짧은 실험, 본 실험 순서로 보관한다.
- 실패한 한 차례의 실험은 삭제하지 않고 실패 이유와 함께 보존한다.
- 실제 결과 파일은 현재 존재하지 않으므로, 현재 문서에서 성능 결론을 쓰지 않는다.
