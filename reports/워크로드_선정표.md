# 1차 파일럿 실행 작업 선정

## 선택한 실행 작업

1차 파일럿에는 **MLPerf Inference v5.1.1의 BERT-Large SQuAD Server 실행 작업**만 사용한다.

이 파일럿의 목적은 여러 인공지능 모델을 비교하는 것이 아니다. 같은 추론 요청을 반복해서 보내면서 HAMi의 사용량 제한과 이웃 작업 조건만 바꿨을 때, 느린 일부 요청의 응답시간이 어떻게 달라지는지 보는 것이다.

## BERT를 선택한 이유

- 모델·입력 자료·실행 코드가 공개되어 같은 조건을 다시 만들 수 있다.
- 한 요청마다 시작과 완료가 있어 응답시간을 측정할 수 있다.
- 초당 요청 수를 고정한 서버 방식으로 실행할 수 있다.
- 모든 조건에서 같은 모델과 같은 입력을 사용해 HAMi 조건만 비교하기 쉽다.
- 첫 파일럿에서 실행 환경을 지나치게 복잡하게 만들지 않는다.

## 이 선택으로 말할 수 있는 범위

이 실험에서 반복적인 변화가 확인되면 다음 정도로 말할 수 있다.

> 공개 BERT 추론 작업과 이번 GPU 환경에서 HAMi 사용량 제한 또는 이웃 제한이 느린 일부 요청의 응답시간과 반복적인 관계를 보였다.

다음과 같이 넓게 말해서는 안 된다.

- 모든 추론 모델에서 같은 현상이 발생한다.
- 실제 기업 서비스의 요청 분포를 재현했다.
- 공식 MLPerf 성능 결과다.
- 생성형 인공지능 서비스에도 같은 크기의 영향이 생긴다.

## 고정한 소스 버전

| 구성 요소 | 고정 버전 |
|---|---|
| HAMi | v2.9.0, `3a006c6ae2f077a2683df7805c43656c07f6dc15` |
| HAMi-core | `5091a2fbe1816df1265490f771346730f29e2c8d` |
| MLCommons Inference | v5.1.1, `6776245e99dce0600cfc9a6fb61efd310f87de3d` |

실제 GPU 파일럿을 끝내기 전에는 다른 모델이나 다른 공개 요청 자료로 범위를 넓히지 않는다.
