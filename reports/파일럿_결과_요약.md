# HAMi 파일럿 결과 요약

## 현재 상태

**실제 GPU 성능 결과는 아직 없다.** 현재 완료한 것은 여섯 조건·30회 설계에 맞춘 하네스 수정과 로컬 합성 실행 검증이다. 합성 실행의 판정은 코드 연결을 확인하는 가짜 결과이므로 발표나 논문에 인용하지 않는다.

## 실제 GPU에서 채울 항목

| 항목 | 현재 값 |
|---|---|
| GPU·드라이버·CUDA | 미확인 |
| 고정한 GPU 동작 속도 | 미정 |
| 실험 시작 허용 온도 | 미정 |
| 측정 장치가 있는 실행 환경의 식별값 | 미측정 |
| 측정 장치가 없는 실행 환경의 식별값 | 미측정 |
| 선택한 공통 초당 요청 수 | 미정 |
| 측정 장치 자체의 응답시간 변화 | 미측정, 5% 이하여야 함 |
| 조건별·작업별 제한 대기 | 미측정 |
| 공통 요청량 처리 여부 | 미측정, 각 조건에서 목표의 98% 이상이어야 함 |
| 완료된 본 실험 | 0/30 |
| 최종 결정 | 미정 |

## 실제 장비 실행 순서

1. GPU 동작 속도와 시작 온도 기준을 정한다.
2. 측정 장치가 있는 실행 환경과 없는 실행 환경을 만든다.
3. Docker, CUDA, 빈 GPU, 입력 파일, 고정 소스 버전을 확인한다.
4. C2·C4·C5의 안정 처리 능력을 각각 찾고 가장 낮은 값의 70%를 공통 요청량으로 정한다.
5. 측정 장치가 응답시간을 5% 넘게 바꾸지 않는지 세 쌍으로 확인한다.
6. C1부터 C5까지 짧게 실행해 역할별 제한 대기와 공통 요청량 처리 여부를 확인한다.
7. 위 검사를 모두 통과한 경우에만 6조건 × 5묶음의 본 실험을 실행한다.
8. 같은 묶음의 C2/C1, C4/C3, C5/C4 비율로 계속 여부를 판정한다.

## 판정 규칙

- 계속: 원인을 분리하는 비교 중 하나 이상이 다섯 묶음 중 네 묶음 이상에서 같은 방향이고, 비율의 가운데 값이 1.10 이상이거나 약 0.91 이하이다.
- 제한적으로 계속: 네 묶음 이상에서 같은 방향이지만 변화 크기가 위 기준보다 작다.
- 중단: 원인을 분리하는 비교에서 반복 변화가 없거나, 실험 유효성 검사를 통과하지 못하거나, 일반적인 자원 경합만 나타난다.

1.10과 약 0.91은 논문의 통계적 유의성을 확정하는 기준이 아니라 후속 계측과 GPU 사용에 비용을 투입할지 정하는 파일럿 기준이다.
